# UniStats

An interactive explorer of Swiss university statistics from the Swiss Federal Statistical Office (BFS/OFS/FSO). Compare student enrolment, entrants, degrees, staff, and finances across universities and years using time-series charts and population pyramids.

[Open the website](https://konspras.github.io/uni-stats/).

Data is collected automatically, archived as timestamped SQLite snapshots, and published as static CSVs for the website. Source definitions and links are available in the interface.

See [the project plan](PLAN.md) and [publishing documentation](docs/STATIC_PUBLISHING.md) for implementation and operation details.
